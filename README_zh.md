# IMA 知识库下载器 v1.0.8

图形界面工具：粘贴 IMA 知识库分享链接 → 微信扫码登录 → 下载**全部文件原件**（PDF / Word / 图片），逐个字节校验 + 页数核对。无需 ima 客户端、无需 OpenAPI 凭证，双击 `start.bat` 即可运行。

> **[English README available here](./README.md)**

## v1.0.8 有什么不同

旧版本（v1.0.4 – v1.0.7）绕着服务端限制打转：OpenAPI 凭证只对「创建者」的库有效，匿名模式只能拿首页预览图，收割通道依赖本机 ima 客户端的残留签名。**v1.0.8 换了路线**：直接复刻 ima 网页端登录（微信扫码），拿到合法登录票据后，用与网页端一致的加密信封协议逐条签发**原件**下载地址——不再有预览图、不再需要客户端、不再需要任何凭证粘贴。

- 📱 **微信扫码登录**：点一下「扫码登录」，微信扫一下即可；票据自动续期，过期才需重扫
- 📋 粘贴分享链接，`share_id` 自动提取
- 📁 递归遍历所有子文件夹，目录结构与知识库完全一致
- ⬇️ **只下原件**：PDF 是完整 PDF（不是首页截图），Word 是完整 docx，图片是原始字节
- 🔬 **下载即校验**：每个文件下载完成立即逐字节比对服务端登记大小；PDF 用 pypdf 解析页数、Word 校验容器、图片校验魔数
- 📄 校验报告自动落盘（`_v108_原件校验报告.json`），收尾打印「原件 N 份 · PDF 合计 P 页 · 共 X MB」
- 🔄 增量下载：已存在且校验通过的文件自动跳过
- ⚡ 多线程下载（默认 8 线程，可关）
- 🌙 暗色主题，中英双语界面

## 快速开始

### 1. 安装 Python

需要 **Python 3.8+**，安装时勾选 **`Add Python to PATH`**（<https://www.python.org/downloads/>）。

### 2. 启动

**Windows：** 双击 **`start.bat`**（首次运行自动安装 `requests` / `cryptography` / `pypdf` 三个依赖）。

**macOS / Linux：**

```bash
pip install requests cryptography pypdf
python gui.py
```

### 3. 使用

1. 打开 IMA 知识库 → **分享 → 复制链接**
2. 双击 `start.bat`，把链接**粘贴**到输入框
3. 第一次使用点 **「📱 扫码登录」**——二维码自动弹出，微信扫一下、手机上点确认（登录态保存在本地 `ima_session.json`，之后一般不用再扫）
4. 点 **「▶ 开始下载」**

收尾会显示：`原件 N 份 · 已存在跳过 M 份 · 失败 0 份 · PDF 合计 P 页 · 共 X MB`，并写一份逐文件校验报告。

## 工作原理（v1.0.8）

1. **扫码登录**：与 ima.qq.com 网页端完全一致的微信 OAuth 流程（qrconnect → 长轮询 → `auth_login/login`），拿到 IMA-TOKEN（2 小时有效，自动续期）
2. **遍历**：`knowledge_share_get/get_share_info` 递归翻页，收齐全部条目与 `media_id`
3. **签发**：`file_manager/get_media` 加密信封协议（AES-128-GCM 请求体 + RSA-OAEP 包裹密钥），逐条换取带签名的原件直链
4. **下载 + 校验**：并发下载到与知识库同名的目录；每个文件字节比对 + 格式解析（pypdf 页数 / Office 容器 / 图片魔数）

> 会话票据明文保存在工具目录 `ima_session.json`，仅本机可见，**勿外传**。

## 常见问题

**Q：为什么要扫码？不扫行不行？**
A：不扫不行——服务端只对登录用户签发原件地址（匿名只能拿首页预览图，这是 v1.0.7 时代的老问题）。扫一次之后票据自动续期，通常很久才需要再扫。

**Q：提示「请先扫码登录」/ 登录过期了怎么办？**
A：点「📱 扫码登录」重新扫一次即可，已下载的文件不会重复下载。

**Q：下载到一半中断了，重跑会全部重来吗？**
A：不会。已存在且大小一致的文件自动跳过（跳过时也会就地复检），只补缺失的部分。

**Q：某个文件失败了怎么办？**
A：日志会显示失败原因，直接重跑一次即可；校验报告里失败项置顶。

**Q：「无法提取 share_id」？**
A：把 IMA 复制的**整段**分享文字直接粘贴，程序会自动提取，不用手动裁。

**Q：校验报告在哪里？**
A：知识库目录下 `_v108_原件校验报告.json`，包含每个文件的字节数、页数与校验结论。

## 目录结构

```
.
├── gui.py             # GUI 主程序（v1.0.8 扫码登录 + 原件管线）
├── ima_auth.py        # 微信扫码登录 / 票据自动续期
├── original_minter.py # 加密信封协议：签发原件直链 + 下载 + 校验
├── traverser.py       # 分享库递归遍历
├── downloader.py      # 文件下载引擎（遍历-下载管线依赖）
├── models.py          # 数据模型
├── api_service.py     # IMA 分享 API
├── main.py            # CLI 入口（可选）
├── requirements.txt   # requests / cryptography / pypdf
├── start.bat          # 一键启动
└── README_zh.md       # 本文件
```

> `sync_manager.py` / `client_harvest.py` / `probe_openapi.py` 为旧版本通道遗留，v1.0.8 起已从仓库移除；`downloader.py` 仍为遍历-下载管线所依赖。
